# Fonts

Place your licensed Neue Haas Grotesk font files here. Suggested structure and filenames:

public/
fonts/
neue-haas/
NeueHaasGroteskText-Regular.woff2
NeueHaasGroteskText-Medium.woff2
NeueHaasGroteskText-Bold.woff2
NeueHaasGroteskDisplay-Regular.woff2
NeueHaasGroteskDisplay-Medium.woff2
NeueHaasGroteskDisplay-Bold.woff2

You can also include `.woff` fallbacks with the same base names.

If you use Adobe Fonts (Typekit), you can skip local files and add your kit instead. See the project README section below.
